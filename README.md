# LimTé

這是一個以台灣手搖茶飲文化為主題的探索與攝取量分析專案。

## 專案簡介

`LimTé` 是由 [jasminechuang](https://github.com/jasminechuang) 所建立與維護的網頁專案。本專案提供台灣知名手搖茶飲品牌（如得正、迷客夏、50嵐、一沐日）的完整英文菜單瀏覽、即時台幣與美元匯率換算，以及個人手搖飲攝取習慣的量化分析功能。

## 技術堆疊

* **主要平台：** GitHub Pages
* **主要應用：** 網頁端互動介面、動態匯率與攝取量記錄系統

```text
LimTe/

```
## 開始使用

如需在本機端檢視或參與此專案，請依照以下步驟進行：

1. 複製專案庫 (Clone the repository)
```text
git clone [https://github.com/jasminechuang/LimTe.git](https://github.com/jasminechuang/LimTe.git)
```
3. 開啟專案
進入專案資料夾後，直接以瀏覽器（如 Google Chrome）開啟 index.html 即可檢視網頁內容。
