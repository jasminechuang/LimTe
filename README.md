# LimTé

這是一個以台灣手搖茶飲文化為主題的探索與攝取量分析專案。

## 專案簡介

`LimTé` 是由 [jasminechuang](https://github.com/jasminechuang) 所建立與維護的網頁專案。本專案提供台灣知名手搖茶飲品牌（如得正、迷客夏、50嵐、一沐日）的完整英文菜單瀏覽、即時台幣與美元匯率換算，以及個人手搖飲攝取習慣的量化分析功能。

## 技術堆疊

* **主要平台：** GitHub Pages
* **主要應用：** 網頁端互動介面、動態匯率與攝取量記錄系統
